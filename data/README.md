# Dataset

This folder contains the dataset used for the House Price Prediction project.

## Dataset

California Housing Prices

## Source

Kaggle:

https://www.kaggle.com/datasets/camnugent/california-housing-prices

## Setup

Download the dataset and place the file here:

```text
data/housing.csv
```

The dataset file is not included in this repository because it is excluded using `.gitignore`.
